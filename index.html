MK1300 V2
CUSTOM RGB

JavaScriptWebHIDHTML/CSSApache-2.0

A browser-based per-key RGB tool for the MK1300 V2 60% keyboard. 90 static patterns, hardware FX, custom presets and animated effects.

Requires Chrome or Edge (WebHID). Close the official MK1300 software before connecting.

// HOW IT WORKS

Four steps, then you're glowing.

  1. Open the tool in a Chromium browser (Chrome or Edge)
  2. Click [ CONNECT ] and select Gaming Keyboard
  3. Click any pattern. It applies instantly
  4. Drag the sidebar edge to resize the preview
!! Only per-key RGB commands are sent. Firmware flash and factory reset opcodes are hardcoded-blocked in the driver, so it cannot brick your keyboard.
